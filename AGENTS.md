## Роутинг Worker'а (worker.js)

```
/               → index.html (лендинг)
/JK-XXXXXX      → passportPage() — паспорт произведения
/clients        → serveClientsList()
/clients/:slug  → serveClient(slug)
/admin          → admin.html
/oferta         → inline HTML
/refund         → inline HTML
/privacy        → inline HTML
/uslugi         → YooKassa payment page
```

## Workflow деплоя

Владелец работает **только с iPhone** (iSH terminal, Safari, GitHub web editor). Desktop отсутствует.

**Безопасный путь изменений:**
1. Редактировать `worker.js` через GitHub web editor (не через iSH — риск замены файла)
2. Commit прямо в `main`
3. Деплой через curl PUT к Cloudflare Workers API

**Проверка перед коммитом:**
- Bash grep-валидация на наличие критических строк
- Убедиться что роутинг не сломан
